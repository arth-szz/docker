O que é Docker?

Docker é uma plataforma de containerização que empacota aplicações e dependências em unidades leves e portáteis chamadas containers. Cada container roda isoladamente, garantindo consistência entre desenvolvimento, testes e produção.

Benefícios do Docker

  • Portabilidade: Containers rodam da mesma forma em qualquer ambiente compatível com Docker.
  • Isolamento: Dependências e configurações não se misturam entre aplicações.
  • Escalabilidade: É fácil criar réplicas de containers para suportar mais tráfego.
  • Desenvolvimento mais rápido: Ambiente consistente entre máquinas de desenvolvedor e servidores.

Como usar este projeto

Este projeto contém um Dockerfile que copia todos os arquivos para a pasta do Nginx e serve este site estático automaticamente.

Comandos principais:

  • docker build -t meu-site . — cria a imagem Docker a partir do Dockerfile.
  • docker run -d -p 8080:80 meu-site — executa o container e expõe o site na porta 8080.
  • docker ps — mostra os containers em execução.
  • docker stop <container-id> — para o container em execução.

Estrutura do repositório

Este repositório contém apenas o essencial para servir uma página estática com Docker:

  • Dockerfile: define a imagem base e copia os arquivos para o servidor Nginx.
  • index.html: conteúdo do site exibido pelo Nginx.

Ao alterar index.html, basta reconstruir a imagem e reiniciar o container para ver as mudanças.
